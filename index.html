Sing-box 1.14.4 yadrosi

Yangi avlod DoH (`type: "https"`), `hijack-dns`, `sniff` rule actionlari va `default_domain_resolver` bilan xatosiz ishlaydi.

☁️

VLESS Reality + WS/TLS + ALPN

Reality TCP bilan birga Cloudflare CDN (`WS + TLS`, `/cdn-ws`, `Host`, `alpn: ["http/1.1"]`, `?ed=`) serverlarini to‘liq qo‘llab-quvvatlaydi.

Smart Auto Failover

Ulanishdan oldin `127.0.0.1:20807` porti va jonli tunnel (`generate_204`) tekshiriladi. Bitta server javob bermasa avtomatik keyingisiga o‘tadi.

Watchdog & MTU 1400
